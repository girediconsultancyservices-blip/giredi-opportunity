# 1. Visitor Journey

Visitor lands on Home Page

↓

Searches for Jobs, Scholarships, Grants, Fellowships or other opportunities

↓

Uses filters (Country, Category, Deadline, Organization, Remote/On-site)

↓

Views Opportunity Details

↓

Clicks Apply

↓

If not registered:

Register or Login

↓

Email Verification

↓

Complete Profile

↓

Upload CV or Build CV

↓

(Optional) Run AI ATS Resume Scanner

↓

Apply Successfully

↓

Receive Confirmation Email

↓

Track Application in Dashboard
